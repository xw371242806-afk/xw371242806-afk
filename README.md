## Featured Project — [OpenMatrix](https://github.com/xw371242806-afk/openmatrix)

[![License](https://img.shields.io/badge/license-Apache--2.0-blue.svg)](https://github.com/xw371242806-afk/openmatrix/blob/main/LICENSE)
[![Release](https://img.shields.io/github/v/release/xw371242806-afk/openmatrix)](https://github.com/xw371242806-afk/openmatrix/releases/tag/v0.1.0)
[![Stars](https://img.shields.io/github/stars/xw371242806-afk/openmatrix?style=social)](https://github.com/xw371242806-afk/openmatrix/stargazers)

**A self-hosted, evidence-first AI research desk** that turns filings, financial reports, and technical documents into auditable outputs with verbatim source quotes and physical page verification.

- **Self-hosted & BYOK:** Connect any OpenAI-compatible endpoint (OpenAI, DeepSeek, local `vLLM` / `llama.cpp`, or internal model gateways); provider keys remain in memory only.
- **Evidence before confidence:** Automatic verbatim quote verification and numeric/entity answer-support checking (`verified_exact` / `supported` / `needs_review`).
- **PDF Evidence Viewer:** Jump directly back to the cited PDF page with text and bounding-box highlights.
- **Agent & Deliverables:** 52 FastMCP tools, bounded Research Agent execution trails, and one-click export to CSV, XLSX, PDF, DOCX, and citation-footnoted PPTX.
